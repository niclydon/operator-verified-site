What a sign-in here does and does not show

Signing in asks World ID — the issuer at auth.world.org — to confirm the account behind this browser session. This site receives a signed token with the account's authentication class and the time the authentication happened. It receives no name, no email, and no raw World identifier; the one identifier in the token is pairwise, minted for this site alone, and it is kept in the session, never displayed or published.

An authentication class of Orb means the account was verified as a unique human at an Orb, which is the claim this program stands for. It is an account's verified status, not a fresh presence proof for this visit: an existing World ID session can issue a new sign-in token without a new proof, so this page shows the authentication time World ID reports alongside the status, and the age of the authentication is part of what is displayed, not something rounded off.
